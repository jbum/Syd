About Syd

Patch editor Renderer GitHub

An instrument editor and software synthesizer by Jim Bumgardner, since 1997.

Syd builds sounds from units wired together with patch cords: oscillators, envelopes, filters, mixers, delays, samples, plucked strings, and scores that play a patch as notes. Almost every setting can be an expression, so a single score unit can make a whole polyphonic piece. It has always been a good way to teach computer music, and it has been used in introductory classes at a few schools.

Jim wrote Syd to reproduce some of the sounds of the Buchla 200 analog synthesizer he played at CalArts in the early 1980s. It soon became a computer-music tool in its own right.

The Whitney Music Box

Syd's best-known use is the Whitney Music Box, a visual and musical toy after John Whitney's ideas about differential motion. Syd rendered its variations that use harmonics and non-standard tunings. The patch behind it is a good example of Syd's unusual way of making polyphony from one score unit. In this video Jim talks about both the Music Box and Syd:

History

1997
Syd, first called SoftSynth, written in C++ for the Macintosh (version 1.0.6).
1998
Ported to Windows as Syd 1.0.7, with built-in help.
2006
JSyd, a rewrite in Java, so Syd ran on modern Macs, Windows and Unix, with a new patch-cord interface. Alongside it, CSyd, a command-line renderer ported from the Windows version, and much faster.
2009
Version 1.5.1: stereo and panning in both.
2011
JSyd and CSyd published on GitHub.
2026
CSyd 2.0 and this site. CSyd's 64-bit bugs were fixed, then it was made several times faster: expressions compiled once, notes rendered in blocks across all cores. It carries its own math library, so every machine, and the WebAssembly build that runs in your browser, renders the same bits. The old patches were checked against 1.5 one by one. The patch editor here follows JSyd's design and uses its original icons, and it renders with CSyd itself.

Source code

Syd is on GitHub at github.com/jbum/Syd. The original JSyd and CSyd are on its master branch; CSyd 2.0 and this site are on the csyd2 branch.
